隐私政策

读取什么。 本工具只申请 Google Sheets 只读权限。虽然 Google 的这项权限覆盖账号可查看的表格，工具只查询用户指定表格的标识和页签属性，包括页签编号、名称、顺序、隐藏状态和网格大小。不会用这项授权读取单元格、访问其他表格或修改数据。

怎么使用和保存。 页签信息只用于本机核对。核对信息和取得时间可留在本机运行记录中。长期授权凭据仅保存在当前 Windows 用户的凭据管理器；工具不接收或保存 Google 密码。工具不向维护者收集表格数据，不将其上传、出售、分享或用于广告。

网站访问。 本站没有表单、访问分析或追踪脚本。托管方 GitHub Pages 可能为安全目的记录访问者的 IP 地址，详见 GitHub Pages 的数据收集说明。

撤销授权。 用户可在 Google 账号的第三方关联 移除本工具的访问，并在 Windows 凭据管理器移除本机授权条目。撤销不会自动清理既有本机记录。有关隐私的问题，可通过 Google 授权页列出的支持邮箱联系维护者。
